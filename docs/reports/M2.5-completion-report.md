## 3. UI implementation

**Project Skills** giữ nguyên sidebar entry và một màn hình với Target Project, Target Providers, Skill Catalog, Scan & Recommend và kết quả. Picker hiện có hỗ trợ root, workspace và absolute path; daemon validation cung cấp canonical directory. Catalog editor và scan dùng chung host settings. Draft chỉ có hiệu lực sau Save.

Target Providers là controlled installation intent. Checkbox vẫn chọn được khi runtime unavailable; discovery chỉ dùng để hiển thị trạng thái. Scan hoạt động với provider selection rỗng. Client dùng React state và Foundation hooks, theme, layout compact, nút và modal có sẵn.

Click scan thực hiện một `catalog.load` để pin descriptors, rồi một `recommendation.evaluate` với expected SHA và settings revision. Recommendation daemon thực hiện project scan. UI hiển thị loading, cancel, partial, stale, offline và typed errors bằng text an toàn; không hiển thị phần trăm progress hoặc stderr.

## 5. Recommendation presentation

Mỗi skill hiển thị ID, description từ catalog cùng SHA, verdict, inventory state và reason tóm tắt. Recommended và Optional mở mặc định. Unknown gấp và vẫn có thể chọn. Khi mở chi tiết, UI hiển thị mỗi positive boundary, reason, catalog ref và projected evidence thật. Occurrences giữ path, layout, boundary, confirmed/candidate, metadata mismatch và flags. Partial giữ usable matches, phân biệt scan coverage với lỗi metadata catalog. Task applicability được ghi rõ là chưa đánh giá. UI chỉ dùng evidence và boundary matches thực tế từ contract v1.

## 6. Selection semantics

Selection bắt đầu rỗng. Manual selection dùng stable Skill IDs ở cả ba nhóm. Select Recommended thêm các skill Recommended vào tập hiện tại. Clear Selection chỉ xóa skill selection. Rescan hoặc đổi host, target hay saved catalog reset kết quả/skill selection. Đổi provider chỉ cập nhật installation intent.

`SelectionIntentV1` được dựng trong bộ nhớ từ host scope, canonical target, pinned catalog source/SHA, settings revision, selected Skill IDs, Target Provider IDs và recommendation request ID. UI chưa cung cấp Preview và intent chưa cấp quyền ghi hoặc overwrite.

## 7. Lifecycle và isolation

Scope kết hợp host, target generation, canonical path, saved ref và revision. Mỗi attempt có request ID riêng. Sau catalog preflight và khi nhận terminal event, client đối chiếu scope, request identity và result provenance trước khi render. Token được vô hiệu hóa khi hủy hoặc scope đổi. SDK subscription unmount khi terminal, cancel, switch, offline hoặc reload. Late catalog replies và duplicate/late events bị bỏ. Reconnect đợi yêu cầu scan mới. Không thêm polling scan, global store hoặc cache mới.
