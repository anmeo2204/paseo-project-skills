## 1. Summary of Implemented Scope (D1–D4 & P1–P4)

| Item | Requirement | Implementation & Verification |
| --- | --- | --- |
| **D1** | Dedicated host-scoped `workspace-preferences` settings | Created `shared/workspace-preferences.ts` (`defineSettings({ id: "workspace-preferences", scope: "host", version: 1 })`) and registered via `server.registerSettings()` in `index.server.ts`. Strictly separate from `catalogSettings` (`catalog`); verified zero `catalogSettings.revision` churn on preference writes. |
| **D2** | Explicit Recent Projects quick-pickers (no auto-select) | Rendered up to 5 recent projects inline in `TargetPicker` as explicit 1-click quick-pickers; verified zero automatic target selection or validation on screen open/reload. Clicking a recent project always revalidates via `target.validate-directory`, with 1-click `Remove from recent` on deleted/unreadable paths. |
| **D3** | `Select Detected Providers` (`enabled && status === "ready"`) | Enabled only after all enabled supported providers finish `loading` and at least one supported provider is `enabled && status === "ready"`. Selects sorted ready supported providers, advances `providerGeneration`, and saves preference. |
| **D4** | Retention caps (`8` recent, `32` canonical roots) | Enforced in `workspacePreferencesSchema` and `applyWorkspacePreferenceMutation()` with deterministic LRU eviction by timestamp. |
| **P1** | Serialized & coalesced preference writes with single conflict retry | Implemented `client/preference-writer.ts` (`coalesceMutations`, `createPreferenceWriter`): strictly serializes writes, coalesces rapid toggles for the same root, and on optimistic concurrency conflict reloads latest settings, merges only the intended mutation batch (including newer queued toggles), and retries at most once. Persistence failures are caught silently and never block Scan, Preview, or Apply. |
| **P2** | Searchable Picker across paginated workspaces | `TargetPicker` fetches all paginated workspace pages (bounded to `20` pages / `2,000` workspaces with explicit truncation notice), filters both project roots and workspaces client-side by name/kind/path, resets search on close, and preserves exact `workspaceDirectory` vs `projectRootPath` without Git root substitution. |
| **P3** | Explicit empty provider preference (`[]`) | `Clear providers` persists `{ providers: [], updatedAt }` under `providerPreferencesByRoot[canonicalDirectory]`. `lookupProviderPreference()` distinguishes `{ found: false }` from `{ found: true, providers: [] }`; restoring an explicit empty preference keeps `[]` and never replaces it with detected providers or defaults. |
| **P4** | Provider snapshot freshness & strict binding | `ProviderSelection` scopes React Query to `["providers", hostId, cwd, selectionGeneration, selectionId]` (`gcTime: 0`, `refetchOnWindowFocus: false`) and binds `Select Detected Providers` / `Clear providers` via `ProviderSnapshotBinding` (`hostId`, `cwd`, `selectionGeneration`). `HostScreen` verifies the active binding before applying; provider status updates never auto-modify `selected`. |
| **UI** | Compact provider chips & collapsed manual entry | Replaced tall vertical provider rows with wrapped compact checkbox pills (`minHeight: 36`, `flexWrap: "wrap"`) preserving exact `accessibilityLabel` semantics. Collapsed manual path entry behind `Disclosure("Advanced: Enter path manually")` (`expanded={false}` by default). |
