## 4. Remaining Limitations & Known Bounds

1. **Step 8 Physical Network/Suspend Waived:** Physical Android Airplane Mode and >60 s background suspend checks were explicitly waived by the user (`SKIPPED (User-waived)`). Offline/reconnect transitions remain covered by automated tests (`tests/operation-tracking.test.mjs`, `tests/preview-ui.test.mjs`).
2. **Cooperative Deadline:** `ApplyJournal.list()` `maxDurationMs` (`2000 ms`) is a cooperative deadline between sequential async filesystem calls, not a hard kernel I/O timeout.
3. **Mutable-Journal Pagination:** Keyset pagination over a live journal without server snapshots requires `Refresh operations` (`cursor = undefined`) to surface newly created/mutated entries sorting ahead of a cursor.
4. **SDK `0.17.4` Trust Model:** No caller principal in SDK `0.17.4` / Paseo `0.18.0`; revoking Relay opt-in immediately blocks future discovery/Apply calls without retroactively erasing data already rendered on a client.
