# M1.2 — Plugin Scaffold & RPC

**Trạng thái** — Hoàn thành triển khai, chờ review. Plugin đang chạy trên daemon Paseo Desktop 0.17.4 từ checkout local.

## File đã tạo

- `paseo-plugin.json`, `package.json`, `package-lock.json`, `tsconfig.json`, `.gitignore`
- `index.client.tsx`, `index.server.ts`, `client/foundation-screen.tsx`, `shared/rpc.ts`
- `README.md` và báo cáo này

## Dependencies và API

Paseo SDK và peers `@getpaseo/client`, `@getpaseo/protocol` pin ở 0.17.4. React và React Native render UI, TanStack Query quản lý trạng thái request, Zod khai báo schema, TypeScript và React types phục vụ typecheck. Các package khai báo ở dev dependencies theo mô hình runtime do Paseo cung cấp.

Client dùng `addScreen`, `addSidebarHeaderItem`, `SidebarRow` và `openScreen`. Cleanup gọi hai hàm hủy đăng ký. `defineRpc`, `server.handle` và `useRpc` nối RPC `foundation.status` với input là object rỗng và output là `{ status: "ready" }`. Paseo thu hồi handler khi dừng subprocess. Handler trả trạng thái cố định, không truy cập filesystem hoặc mở agent.

## Sai khác và bước chuẩn bị M1.3

Không có blocker trong M1.2. Scaffold được tạo trực tiếp theo contract 0.17.4 vì `plugin init` yêu cầu thư mục trống. Kiểm thử lifecycle thực hiện trên Desktop/local daemon. Chưa kiểm tra mobile hay remote host.

M1.3 có thể dùng `usePaseo().projects.list()` và `workspaces.list()` để chọn Git hoặc non-Git project, phân biệt root của project với thư mục worktree và xác nhận đường dẫn tuyệt đối trên đúng host bằng RPC chỉ đọc. Provider discovery dùng cwd đã xác nhận. Catalog settings theo host lưu ref mặc định trống với nguồn Project-Skills cố định. Native folder picker tiếp tục được hoãn.

M1.2 dừng ở scaffold và kiểm tra kết nối. Repository chưa được commit hoặc push.
