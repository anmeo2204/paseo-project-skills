## 5. Residual Risks & Release Checklist

### Residual Risks (đã chốt ở kiến trúc Single-user Local Host)
1. **SDK `0.17.4` thiếu caller principal:** Receipt không phải bằng chứng mật mã về danh tính người bấm duyệt; mọi tiến trình local cùng user truy cập daemon đều cùng trust boundary.
2. **Kernel race window khi move thư mục:** Move thư mục gốc giữa `linkage()` cuối và `openat`/`mkdirat` có thể tạo tối đa 1 entry trong thư mục cũ trước khi dừng `linkage_changed` (thư mục thay thế không bị ghi).
3. **Create-only không auto-rollback:** Crash/ENOSPC giữa chừng để lại file `0600` dở; cần đối soát thủ công qua `apply.status.v1` + ledger.
4. **Chưa hỗ trợ Skill Update / Overwrite / Uninstall:** Conflict chặn toàn bộ plan.
5. **Giới hạn nền tảng:** Chỉ macOS arm64 + local APFS case-insensitive + Paseo `0.17.5..0.17.x`.

## 6. Đề xuất quy trình nâng cấp Plugin chính & Phương án quay lại Preview-only

### Quy trình nâng cấp (chỉ thực hiện sau khi User phê duyệt)
1. Commit toàn bộ thay đổi M4.P2 trên branch `main` (hoặc tạo tag release `v0.2.0-safe-apply-rc1`).
2. Reload plugin chính trên `~/.paseo`:
   ```sh
   PASEO_DESKTOP="/Applications/Paseo.app/Contents/Resources/bin/paseo"
   "$PASEO_DESKTOP" plugin reload paseo-project-skills
   "$PASEO_DESKTOP" plugin logs paseo-project-skills
   ```
3. Kiểm tra trạng thái mặc định Preview-only trên Desktop: xác nhận banner báo đúng trạng thái (nếu `daemon.relay.enabled: true` → báo Relay fail-closed; nếu tắt Relay và chưa enroll → báo chưa có root nào được enroll).
4. Chỉ khi sẵn sàng dùng cho một project cụ thể (với Relay tắt), chạy out-of-band CLI:
   ```sh
   node --import ./tests/register.mjs scripts/enroll-project-skills.mjs enroll --root /abs/path/to/project
   ```

### Phương án quay lại Preview-only tức thì (Rollback Plan)
- **Tắt nhanh không cần reload plugin (tức thì):**
  - Tắt từng project: `node --import ./tests/register.mjs scripts/enroll-project-skills.mjs disable --root <root>` (hoặc `revoke`).
  - Hoặc bật lại `daemon.relay.enabled: true` → Safe Apply tự động fail-closed về Preview-only cho toàn bộ daemon, trong khi `apply.status.v1` vẫn đọc được lịch sử.
- **Rollback code hoàn toàn về Preview-only:**
  - `git checkout af40e3074529a53be37380e24d946676c3022d52` (hoặc revert commit M4.P2) rồi chạy `"$PASEO_DESKTOP" plugin reload paseo-project-skills`.
