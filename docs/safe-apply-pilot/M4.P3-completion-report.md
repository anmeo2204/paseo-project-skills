## 3. Đánh giá & Tương thích Paseo 0.18.0

- **Đánh giá SDK `@getpaseo/{client,plugin,protocol}` `0.17.4` vs `0.18.0`:**
  - Toàn bộ RPC & subscription contract hiện tại (`foundation.status`, `target.validate-directory`, `catalog.load`, `settings.catalog.*`, `target.scan`, `recommendation.evaluate`, `preview.canonical`, `preview.providers`, `preview.providers.v2`, `apply.target-status.v1`, `apply.create.v1`, `apply.status.v1`) hoạt động tương thích 100% giữa SDK `0.17.4` và Paseo `0.18.0`.
  - Paseo `0.18.0` **chưa bổ sung caller principal** trong `PluginHandlerContext` và chưa bổ sung `pluginDir` trong `PluginServerContext`.
  - **Quyết định:** Giữ nguyên SDK pinned tại **`0.17.4`** (không nâng dependency không cần thiết, bảo toàn tương thích ngược với Paseo `0.17.5` và tránh supply-chain delta).
- **Đồng bộ Compatibility Policy & Native Writer Gate:**
  - [server/compatibility-policy.ts](../../server/compatibility-policy.ts) (`policyVersion: "m4.p3-v1"`): mở chính xác cho **`0.17.5 <= v < 0.18.0`** và **`0.18.0`** (chặn fail-closed `0.17.4`, `0.18.1`, `0.19.0+`).
  - [native/anchored-writer.m](../../native/anchored-writer.m): cập nhật `platformGate` đồng bộ `(pMaj == 0 && pMin == 17 && pPat >= 5) || (pMaj == 0 && pMin == 18 && pPat == 0)`.
  - Rebuild & `codesign --verify --strict` thành công:
    - `native/anchored-writer.m` SHA-256: `1e0351cc3ba9c806b75ca87c6db0cf7ec9524ebc17b282665b1119fccb7d92bd`
    - `standard` binary SHA-256: `6324edff5ef723905a1c30c2c0270f892eea2187464d729c5d14949e4e7adfe6`
    - `testing` binary SHA-256: `7c6668cfb76cfa0cbb1a92318a445bf4f45c2889c8e8ba9a3ae6980330aa14ca`

## 6. Residual Risks

1. **Chưa có Caller Principal trên Paseo `0.18.0` / SDK `0.17.4`:** Mọi tiến trình local cùng user truy cập daemon đều nằm chung trust boundary Single-user Local Host; Relay bắt buộc tắt khi Apply và enrollment bắt buộc qua CLI out-of-band.
2. **Chỉ mở chính xác Paseo `0.18.0` (chặn `0.18.1+`):** Khi Paseo Desktop tự nâng cấp lên `0.18.1+`, Safe Apply sẽ chủ động fail-closed về Preview-only cho tới khi phiên bản mới được kiểm chứng và cập nhật vào policy + native writer.
3. **Create-only không auto-rollback & kernel move race:** Giữ nguyên giới hạn kiến trúc từ M4.P2 (crash/ENOSPC để lại file dở `0600` cần đối soát thủ công qua `apply.status.v1`; không hỗ trợ overwrite/uninstall).
4. **Giới hạn nền tảng:** macOS `arm64` (`>= 14.0.0`) + local APFS case-insensitive.
