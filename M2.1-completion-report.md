## Resolver và discovery

- Loader fetch SHA đầy đủ hoặc ref tường minh trong `refs/tags/` từ Project-Skills qua SSH. SHA phải đúng object ID và type `commit`. Lightweight và annotated tag được peel về commit SHA trước khi đọc tree. Bare name trùng branch chỉ resolve khi có tag cùng tên. Missing ref, branch-only và tag trỏ non-commit trả lỗi.
- Discovery theo `skills/<slug>/SKILL.md` trong Git tree đã pin. Slug là ID ổn định và phải khớp `name`. Parser YAML đọc frontmatter, Zod validate `name` và `description`. Thiếu entrypoint, metadata sai hoặc trùng ID làm hỏng cả snapshot. Skill và file có thứ tự cố định. Supporting files gồm các Git blob thường trong thư mục skill, bao gồm license, file lồng và file nhị phân.

## Snapshot, cache và RPC

Snapshot nội bộ có `schemaVersion`, `source`, `commitSha` và danh sách skill. Mỗi skill có ID, directory, metadata, entrypoint và supporting files. Mỗi file giữ path, blob SHA, size, Git mode và raw bytes cùng commit. `catalog.load({})` đọc host settings một lần, trả `settingsRevision`, `requestedRef` và snapshot dạng metadata/file descriptors. Lỗi có mã và diagnostics khi áp dụng.

LRU trong bộ nhớ giữ tối đa hai snapshot đã validate của source cố định, theo resolved SHA. Các yêu cầu trực tiếp cùng SHA đang tải dùng chung công việc. Mỗi request tag resolve lại qua remote trước khi tra cache. Loader chỉ publish snapshot đầy đủ, loại bỏ công việc lỗi và thu hồi cache khi dispose.

## Security controls và resource limits

- Git spawn bằng argv với `shell: false`, env được chọn lọc và bare staging riêng trong temp của daemon. Shallow fetch, explicit ref, SSH non-interactive, tắt auto-follow tag, recurse submodule, hooks và replacement refs. Loader đọc raw blob theo OID trong tree và giữ catalog code, Markdown links dưới dạng dữ liệu.
- Reject symlink, gitlink, Git mode sai, path không an toàn và UTF-8 lỗi. YAML từ chối duplicate keys, aliases, merge keys và explicit tags. RPC chỉ gửi lỗi đã lược bỏ raw stderr và không gửi bytes.
- `server/catalog-limits.ts` giới hạn 512 skills, 2.048 entries, 512 byte/path, 256 byte/ref, 128 KiB/entrypoint, 1 MiB/blob, 8 MiB/snapshot, 512 KiB descriptor JSON và 32 diagnostics. Hai cold requests có thể staging đồng thời, request staging tiếp theo nhận `limit_exceeded`. Cold load có deadline 20 giây và ngưỡng staging 64 MiB mỗi lượt.
- Staging được dọn khi thành công, lỗi, timeout hoặc dispose. Trên macOS, timeout/dispose hủy Git process group. Ngưỡng staging được lấy mẫu trong fetch và kiểm tra sau fetch, nên dung lượng có thể vượt ngắn hạn giữa hai lần đo.
