# M1.4 — Foundation Verification

**Kết luận: GO cho M2 trong phạm vi local-first.** Foundation đã qua typecheck, 15 automated tests và smoke test trên Desktop/daemon Paseo 0.17.4. Chờ người dùng duyệt thay đổi trước khi commit M1.4.

| Screenshot M1.3 hiển thị hostname và đường dẫn fixture | Ảnh chụp runtime còn dữ liệu riêng của máy. | Che hai giá trị và bỏ metadata. Giữ ảnh chụp thật cùng chú thích về phần đã che. |

Đã rà soát lifecycle, ranh giới SDK client/server, typed RPC, xử lý lỗi filesystem, cách phân biệt root/worktree, host-scoped settings và dependency compatibility. Client hủy hai đăng ký khi dispose. Server handlers thuộc vòng đời subprocess, hiện không có timer hay tài nguyên riêng cần thu hồi. Directory validation chỉ kiểm tra thư mục đã có. Cơ chế host/target remount và query key hiện có xử lý response đến trễ trong các kịch bản đã test. Không phát hiện lỗi Foundation chưa xử lý chặn M2.

## Automated test

**PASS — 15/15, không skip** trên Node 22.23.4. `npm ci` và `npm run typecheck` đều PASS.

- **6 test contract và filesystem thật.** Dùng fixture tạm, dọn sau test. Bao phủ Git/non-Git, absolute, relative, missing, file, NUL, symlink canonicalization và permission thật bằng mode `000`. Kiểm tra settings mặc định trống, full SHA, tag, ref lỗi, abbreviated SHA, `HEAD` và branch ref tường minh. Kiểm tra đăng ký RPC, input/output schema và scope host.
- **9 test screen với host/transport giả lập.** Render component và registration thực, dùng React Query cùng SDK RPC context thật. Bao phủ loading/ready/unavailable/error, nhiều lựa chọn, reset và khóa provider không sẵn sàng, provider A về sau B, validation A về sau B, chuyển host, offline/reconnect, thay installation sau unmount và retry. Test settings dùng hai host fixture có cùng revision ID để xác nhận ref/draft không bị mang sang host mới và Save đi đúng host.
- **Branch policy.** M1.4 chỉ kiểm tra cú pháp và lưu ref và chưa có resolver. Bare ref được coi là tên tag, explicit branch ref bị từ chối. Không có đường thực thi fallback sang branch để gọi trong suite. M2 cần test resolver chỉ tra namespace tag hoặc full SHA.

Dùng Node built-in test runner và TypeScript đã có. Thêm duy nhất một dev dependency trực tiếp, `react-test-renderer@19.1.0`, khớp React 19.1 để mount hooks/component thật trong Node. Renderer có cảnh báo deprecated và chỉ dùng trong test. npm cũng phát cảnh báo deprecated cho một số dependency bắc cầu đã có trước. Dependencies dùng trong plugin và phiên bản SDK giữ nguyên.
